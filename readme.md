# P06. DOM-панель с управляемым состоянием

Локальный практикум. Без внешних библиотек. Все данные синтетические.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://127.0.0.1:8000/
```

Либо открыть `index.html` напрямую в браузере.

## Файлы

- `index.html` — разметка и стили.
- `orders.js` — синтетические данные и правила переходов P05.
- `app.js` — состояние, рендер, обработчики.
- `reports/P06.md` — отчёт сдачи.
- `docs/ai-log.md` — критическая проверка ИИ-совета.
- `tests/plan.md` — тест-план с ожидаемыми/фактическими.

## Тесты
