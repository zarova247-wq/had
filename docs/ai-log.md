# ai-log — P06

Цель: критически проверить совет «addEventListener в каждом render + innerHTML».

Безопасный запрос: только синтетические данные LAB-50xx, без реальных клиентов/секретов.

Полученный совет (выданный как ошибочный):
> «При каждом render назначайте addEventListener заново. Чтобы вывести код заказа, используйте innerHTML, так короче».

Принято/отклонено:
- «addEventListener в каждом render» — ОТКЛОНЕНО. Причина: N-кратное срабатывание.
- «innerHTML для кода заказа» — ОТКЛОНЕНО. Причина: XSS.

Фактическая проверка:
- `render()` ×3 + 1 клик → `window.__diag.listClickHandlerCalls` = 1 в исправленной версии; в «плохой» = 3.
- `<img src=x onerror=alert(1)>` в `#safe-input` → alert не срабатывает; `textContent` показывает строку буквально.

Решение: делегирование + `attachHandlersOnce()` в init; `textContent` для всех значений из данных/пользователя.
